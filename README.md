# DAppWane

DAppWane is a distributed, decentralized framework for real-time data processing and analytics, leveraging auto-scaling engines.

DAppWane is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DAppWane.git`
2. `cd DAppWane`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DAppWane, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
